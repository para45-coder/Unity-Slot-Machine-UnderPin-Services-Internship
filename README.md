# 🎰 Slot Machine Game

A slot machine game built with Unity for the internship assignment.

## 🎮 How to Play
- Click **SPIN** to spin the reels
- Win when **all 3 symbols match**!
- Use **+** and **-** to change bet amount
- Your balance updates automatically

## 🎯 Features
- ✅ Smooth reel spinning animations
- ✅ Random outcomes using RNG
- ✅ Win detection and payouts
- ✅ Balance and bet management
- ✅ Clean OOP code structure

## 📂 Project Structure
- `Assets/Scripts/` - Game logic (ReelManager, SlotMachineGame)
- `Assets/Prefabs/` - Reusable game objects
- `Assets/Resources/` - Symbol data assets
- `Assets/UI/` - User interface elements

## 🚀 How to Run
1. Clone or download this repository
2. Open in Unity (2021.3 or newer)
3. Open the main scene
4. Press **Play** in the Unity Editor
